# agent-harness-design

Runnable examples, tests and tutorials for a series on designing the harness around an AI agent.
The harness is the code around the model. It builds each request, runs the tools, writes what
the model reads next and sets the limits.

Each part of the series gets its own folder here. Part 1, on the loop and what the model reads
back, comes first.
